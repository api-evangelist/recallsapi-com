recallsapi.com provides a US recalls API and monitoring service for marketplace sellers. It aggregates recall records from nine US agencies—including CPSC, FDA, NHTSA, US Coast Guard, FAA—and offers alerts via email, signed webhooks, and a REST API. The service is sold by PrimeZen LLC and supports integration with Amazon, Walmart, eBay, and Shopify platforms. Developers can obtain an API key instantly, explore quickstart guides, and use the MCP server for bulk monitoring. The platform emphasizes compliance, safety, and easy integration for e‑commerce businesses.

**Areas:** Company · API · Recall · E-commerce · Safety · US-Agencies

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for recallsapi-com: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
